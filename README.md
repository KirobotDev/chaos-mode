# 🎉 Chaos Mode

**Une extension Chrome qui déchaîne le chaos sur n'importe quelle page web !**

![Chaos Mode](icons/icon128.png)

## ✨ Effets disponibles

| Effet | Description |
|-------|-------------|
| 🔤 **Comic Sans** | Toute la page en Comic Sans |
| 🙃 **Upside Down** | La page entière est retournée |
| 📳 **Shake** | Des éléments aléatoires tremblent |
| 🌟 **Emoji Trail** | Des emojis suivent ta souris |
| 🌈 **Rainbow** | Le texte scintille de toutes les couleurs |
| 🌀 **Spin** | Des éléments se mettent à tourner |
| 🌫️ **Blur** | Flou artistique aléatoire |

## 🚀 Installation (mode développeur)

1. **Clone** ce repo ou télécharge-le en ZIP
2. Ouvre Chrome et va sur `chrome://extensions/`
3. Active le **Mode développeur** (en haut à droite)
4. Clique sur **Charger l'extension non empaquetée**
5. Sélectionne le dossier du projet
6. La extension est chargée ! Clique sur l'icône dans la barre d'outils

## 🎮 Utilisation

1. Va sur n'importe quelle page web
2. Clique sur l'icône **Chaos Mode** dans ta barre d'outils
3. Active les effets un par un ou clique sur **🔥 CHAOS TOTAL**
4. Ajuste l'**intensité** avec le curseur (1 = subtil, 5 = maximum)
5. Pour tout arrêter, clique sur **⏹️ STOP**
